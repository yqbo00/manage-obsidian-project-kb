# One-request upgrade

在 `/kb-upgrade` 或用户要求“一次完成 Skill、项目与知识库升级”时读取。本文件编排现有初始化、规则迁移和诊断流程；不是独立的 Shell 安装器。`/kb-upgrade --check` 全程只读，只输出发现和计划。

## Scope and interaction

- 默认范围：当前会话实际使用的 Skill 安装、当前代码项目配置的客户端桥接、该项目的知识目录及其 Shared 规则。Shared 影响同一 Vault 的其他项目，但不自动访问或修改其他代码仓库、其他客户端的独立安装或其他机器。
- 一次请求包含上述兼容性整理授权；简短说明范围后连续执行，不逐步询问、不要求用户手动接力运行 `/kb-init`、整理提示词和 `/kb-doctor`。
- `--auto-migrate` 或等价的明确请求还按 `references/auto-migration.md` 记录本机当前安装的限协议授权。其他项目不在本次扫描；之后实际使用时自动迁移，不要求用户逐项目再次运行升级。普通升级保留已有授权状态，不静默启用或关闭。
- 仅在关键来源或目标身份无法确定、宿主要求权限时请求所需信息/审批。规则迁移中的歧义不逐条打断：保留原规则与兼容加载，完成独立且可安全推进的项，最后集中报告。
- 若不可读的 Mandatory 无法排除与升级操作相关，遵循规则加载协议暂停受影响写入；不得以“升级”为理由绕过现有约束。不要把只读检查或计划视为允许执行升级。

## 1. Identify source and installed target

解析 Project_Root，读取实际加载的 SKILL.md 及当前项目配置，识别安装方式（复制、软链接、项目内安装或客户端管理）。读取 `references/agent-adapters.md`、`references/rule-loading.md` 和升级涉及的 Markdown 模板。

发布来源按用户指定来源、`references/migration-check.md` 中匹配实际安装的本机记录/旧项目 `.ai/kb-backups/upgrades/source.json`、Skill 自身仓库 remote 的顺序确定；不能把当前业务项目的 origin 当成 Skill 来源。若来源不明，只询问一次仓库 URL 或新版包路径，不猜测同名仓库。用户已指定本地新版包时可直接使用，并标注“本地版本”，不声称是 GitHub 最新版本。

网络可用时解析该来源的最新稳定 Release 到具体标签/提交；没有 Release 时使用已确定的来源默认分支并记录提交 ID，明确它是分支版本。用户指定版本优先。下载完整 Skill 包到临时目录，检查 name、必需资源、模板及目标升级说明；不直接执行网络内容中的安装命令。不能联网或查不到版本时，可继续将现有安装协议应用到项目，但最终将“最新版核对/安装”标为 Pending，不能声称完成最新版本升级。

“远端最新”可能早于本机未发布版本。核对发布版本、已记录提交及桥接/配置协议，不以下载时间判断新旧；目标缺少当前升级协议或明显更旧时，不自动降级。无法比较且本地存在定制/未发布改动时保留当前包并报告安装 Pending，可按当前协议完成无冲突的项目升级。

## 2. Back up and update the package

先比较实际内容，仅有差异时保存完整旧 Skill 包及受影响文件清单到客户端不会扫描的私有备份目录。保留可追溯的目标版本与来源；备份中可能含本机路径，不写入可提交文档。

- 复制安装：在备份和校验后替换目标包；保留用户定制差异，不直接以新包覆盖无法合并的修改。
- 软链接：更新已确定的链接目标；脏工作树不得 reset/强推。不能安全更新时报告冲突，不悄悄切换安装位置。
- 客户端管理安装：优先使用其可用的更新入口；不可自动操作时明确报告安装未完成。
- 只处理本次已确定的实际安装，不扫描并覆盖所有同名目录。独立的其他客户端安装列入剩余事项。

读回新版包。若包内容已更新，重新读取其中的 SKILL.md、升级协议与模板再处理项目，避免继续执行旧会话缓存的迁移规则；继续受用户本次授权范围约束。需要客户端重启才能发现新资源时说明这一限制，不承诺能让宿主即时热重载。

来源信息待补充、联网失败或安装权限被拒绝时，仅将包步骤标为 Pending；现有包经核对仍完整可用时，可继续当前协议支持、无依赖冲突且已授权的项目步骤。包部分写入或完整性不明时暂停依赖项，先根据备份恢复或修复一致的包；不把新旧协议混合使用，不擅自换安装路径绕过权限。

## 3–5. Project, rules and verification

安装核验后读取 `references/project-migration.md`，连续完成当前项目桥接、规则迁移及验证，不要求用户逐条执行命令。--check 只预览；来源不明或安装 Pending 时按上述依赖边界处理。没有项目绑定时只在用户允许的初始化向导中取得必要选择，不从全局记录猜测。
